# Sudoku Solver

A simple Sudoku Solver made using **Python and Tkinter**.

## What I Used

* Python
* Tkinter for GUI
* Backtracking algorithm

## What It Does

The program provides a 9x9 Sudoku grid where the user can enter a puzzle and solve it automatically.

It checks the **rows, columns, and 3x3 boxes** before placing numbers.

### Features

* Solve Sudoku
* Load an example puzzle
* Clear the grid
* Invalid input and no-solution messages

## How to Run

```bash
python sudoku_solver.py
```

The GUI will open and you can enter your Sudoku puzzle.
